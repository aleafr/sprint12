# Sprint 12 — Automação e Dashboard

Projeto desenvolvido durante o bootcamp de Data Analytics da TripleTen.

## Objetivo

Criar um dashboard analítico automatizado utilizando Tableau Public para visualização e acompanhamento de métricas de negócio.

## Descrição

Neste projeto foram realizadas:
- extração e preparação de dados;
- criação de dashboard interativo;
- análise visual de métricas e tendências;
- automatização do fluxo de análise;
- publicação do dashboard no Tableau Public;
- apresentação visual dos resultados em formato profissional.

## Tecnologias utilizadas

- Python
- Pandas
- Tableau Public
- Jupyter Notebook

## Arquivos

- trend_by_time.csv
- dashboard_link.txt
- presentation.pdf

## Dashboard

O dashboard foi publicado no Tableau Public para visualização interativa dos dados e métricas analisadas.
